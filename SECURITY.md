# Security policy

Please report vulnerabilities privately to **support@cosmobots.io** with
"SECURITY" in the subject. Do not open a public issue for a security problem.

We aim to acknowledge reports within three business days and will keep you
informed while a fix is prepared.

Never include real credentials, customer data or tokens in an issue, a pull
request or a commit. Configuration belongs in environment variables; the
`*.env.example` files document every variable with placeholder values only.
